# Start hier

Project Health Check controleert of de belangrijkste onderdelen van je project aanwezig zijn.

De controle kijkt ook of oefenmodules goed in de catalogus staan.

Hij verandert niets.

## Starten

Kies in VS Code:

**Terminal > Run Task... > Project Health Check**

Lees daarna de eindstatus:

- **Gezond:** alles klopt;
- **Aandacht nodig:** controleer de waarschuwingen;
- **Ongezond:** één of meer verplichte onderdelen ontbreken of zijn ongeldig.
