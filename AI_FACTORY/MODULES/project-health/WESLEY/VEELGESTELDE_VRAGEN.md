# Veelgestelde vragen

## Verandert de Project Health Check bestanden?

Nee. De taak leest alleen bestanden en mappen.

## Registreert de taak een ontbrekende module?

Nee. Je krijgt alleen een waarschuwing met het pad.

## Wat betekent Aandacht nodig?

Er is geen harde fout, maar iets moet handmatig worden beoordeeld.

## Wat betekent Ongezond?

Een verplicht bestand, map of catalogusonderdeel ontbreekt of is ongeldig.

## Lost de taak dubbele module-ID's op?

Nee. Hij meldt welke ID dubbel staat. Laat daarna eerst bepalen welke registratie correct is.

## Voert de taak Git-commando's uit?

Nee. De Project Health Check gebruikt Git niet.
