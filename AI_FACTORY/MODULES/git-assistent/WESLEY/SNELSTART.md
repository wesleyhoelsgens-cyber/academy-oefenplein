# Snelstart

1. Open VS Code.
2. Kies **Terminal**.
3. Kies **Run Task...**.
4. Kies **Git Assistent**.
5. Kies een nummer uit het dashboard.
6. Kies `7` wanneer je direct wilt weten wat je nu moet doen.
7. Na iedere keuze kom je terug in het menu.
8. Kies `0` of `Q` om af te sluiten.
9. Voer alleen aanbevolen commando's uit als je begrijpt wat ze doen.

De Git Assistent geeft alleen advies en verandert niets.
