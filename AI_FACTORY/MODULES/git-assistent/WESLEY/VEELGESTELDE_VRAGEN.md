# Veelgestelde vragen

## Doet de Git Assistent zelf een commit?

Nee. Hij toont alleen advies.

## Doet de Git Assistent zelf een push?

Nee. Jij beslist zelf of je `git push` uitvoert.

## Wat betekent working tree clean?

Alle lokale wijzigingen zijn opgeslagen in Git.

Er zijn geen losse wijzigingen om te committen.

## Wat is een branch?

Een branch is een aparte werklijn in Git.

Je kunt daar veilig aan een wijziging werken.

## Wat betekent staged?

Deze wijzigingen staan klaar voor de volgende commit.

## Wat is een upstream?

Dat is de gekoppelde branch op GitHub.

Git gebruikt die koppeling voor push en pull.

## Wat moet ik doen bij een merge conflict?

Stop met committen en pushen.

Lees welke bestanden conflicteren.

Vraag hulp als je niet zeker weet welke inhoud moet blijven.

## Kan ik iets kapotmaken door de Git Assistent te starten?

Nee. De Git Assistent leest alleen de status.

Hij verandert geen bestanden en voert geen Git-wijzigingen uit.
