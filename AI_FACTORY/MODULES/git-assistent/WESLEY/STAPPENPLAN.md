# Stappenplan

```text
Wijzigingen maken
       ↓
Git Assistent starten
       ↓
Status lezen
       ↓
Wijzigingen controleren
       ↓
Commit maken
       ↓
Push uitvoeren
```

## 1. Wijzigingen maken

Werk aan je project.

## 2. Git Assistent starten

Kies **Terminal > Run Task... > Git Assistent**.

## 3. Status lezen

Lees wat gewijzigd, nieuw of al staged is.

## 4. Wijzigingen controleren

Gebruik alleen het advies dat bij jouw situatie staat.

## 5. Commit maken

Maak pas een commit als je de wijzigingen hebt gecontroleerd.

Een commit is een lokaal herstelpunt.

## 6. Push uitvoeren

Push pas als de commit klopt.

Daarmee stuur je de commit naar GitHub.
