# Start hier

De Git Assistent opent een Git Dashboard.

Hij laat zien:

- op welke branch je werkt;
- welke bestanden zijn gewijzigd;
- welke wijzigingen klaarstaan;
- of commits nog naar GitHub moeten.

De Git Assistent verandert zelf niets.

Hij maakt geen commit.

Hij doet geen push.

## Starten

Kies in VS Code:

**Terminal > Run Task... > Git Assistent**

Kies daarna een nummer in het menu.

- `1`: Git-status
- `2`: wijzigingen bekijken
- `3`: aanbevolen stappen
- `4`: dashboard vernieuwen
- `5`: Git-uitleg
- `6`: repository controleren
- `7`: direct advies over wat je nu moet doen
- `0` of `Q`: afsluiten

Jij kiest zelf of je een commando uitvoert.
