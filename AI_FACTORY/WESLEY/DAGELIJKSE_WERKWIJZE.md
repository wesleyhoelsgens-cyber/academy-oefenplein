# Dagelijkse werkwijze

Gebruik iedere dag dezelfde volgorde.

```text
Project openen
      ↓
Taak starten
      ↓
Ontwikkelen
      ↓
Testen
      ↓
Git controleren
      ↓
Pushen na toestemming
```

## 1. Project openen

Open altijd eerst de juiste projectmap in VS Code.

## 2. Taak starten

Kies **Terminal > Run Task...**.

Start alleen een taak waarvan je het doel begrijpt.

## 3. Ontwikkelen

Werk aan één duidelijke opdracht tegelijk.

Lees eerst het plan.

## 4. Testen

Controleer of de wijziging werkt.

Lees foutmeldingen helemaal.

## 5. Git controleren

Controleer welke bestanden zijn gewijzigd.

De Git-handleiding wordt later uitgebreid.

## 6. Pushen

Push alleen na controle en duidelijke toestemming.

Twijfel je? Stop en vraag om hulp.
