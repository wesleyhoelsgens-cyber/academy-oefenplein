# Start hier

AI Factory is een vaste werkplek voor slimme hulpmiddelen.

Deze hulpmiddelen noemen we modules.

## Waar staan de modules?

Nieuwe modules komen in:

```text
AI_FACTORY/MODULES/
```

Iedere module krijgt een eigen map.

## Waar staan jouw handleidingen?

Jouw dagelijkse uitleg staat in:

```text
AI_FACTORY/WESLEY/
```

Een module kan ook een eigen map `WESLEY/` hebben.

## Hoe voeg je een module toe?

1. Kopieer `AI_FACTORY/MODULES/TEMPLATE/`.
2. Geef de nieuwe map een duidelijke naam.
3. Vul de lege voorbeelden in.
4. Test de module.
5. Laat de module controleren voordat je hem gebruikt.

## Waar zie je VS Code taken?

Open in VS Code:

**Terminal > Run Task...**

Nieuwe taken verschijnen daar nadat ze veilig aan `.vscode/tasks.json` zijn toegevoegd.

Voor het interactieve Git Dashboard:

**Terminal > Run Task... > Git Assistent**

Kies `0` of `Q` om het dashboard af te sluiten.

Wil je weten wat je iedere dag doet? Open `DAGELIJKSE_WERKWIJZE.md`.
